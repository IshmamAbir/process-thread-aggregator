# Programming Assignment

## English Translation

### Assignment

Create a program that performs the following operations. Also create test code for the program.

- Start **M threads**. In each thread, generate a random integer from **0 through 9** every **0.01 seconds**.
- Start **N processes**, each of which performs the operation above.
- Start one additional process that aggregates the integers generated by the N producer processes at **one-second intervals**. The program therefore runs **N + 1 processes** in total.
- For each integer from 0 through 9, count how many times it was generated during each one-second interval. Print the result as JSON in the following format:

```json
{
  "time": "1458004283",
  "counts": {
    "0": 129,
    "1": 117,
    "2": 121,
    "3": 125,
    "4": 118,
    "5": 120,
    "6": 116,
    "7": 124,
    "8": 119,
    "9": 123
  }
}
```

`time` is Unix time in seconds. A record whose time is `1458004283` counts integers generated at or after Unix time `1458004283` and before `1458004284`.

- All N + 1 processes must support continuous, long-running operation.
- The program must run in memory without using external storage.
- Use a collection from the standard library that is **not thread-safe**, and implement the required mutual exclusion yourself.
- Design the program with scalability in mind.
